## TVPN چیه؟

TVPN یه کلاینت VPN خط فرمانیه که روی **Termux، لینوکس، مک و ویندوز** اجرا می‌شه. هسته‌ی [Xray-core](https://github.com/XTLS/Xray-core) رو خودش دانلود می‌کنه و ابزارهای ترمینال (`pip`، `npm`، `git`، `curl`، `wget` و ...) رو از کشوری که انتخاب می‌کنی رد می‌کنه.

کل کار تو فضای کاربره، پس **روت لازم نیست** و **نیازی به نصب اپ VPN** نداری.

## امکانات

- رابط ترمینال رنگی با بنر بزرگ؛ صفحه در هر بار اجرا پاک می‌شه
- انتخاب کشور با نمایش تأخیر (ping) زنده
- **فال‌بک خودکار**: اگه سروری وصل نشه، سرور بعدیِ همون کشور رو امتحان می‌کنه
- تست واقعی اتصال بعد از وصل شدن و نمایش IP خروجی
- پشتیبانی از ساب‌لینک (ساده یا base64) و دستور `tvpn update`
- پروتکل‌ها: **VLESS** (با Reality)، **VMess**، **Trojan**، **Shadowsocks**
- `tvpn run <دستور>`: فقط همون یه دستور از تونل رد بشه
- `tvpn tools on|off`: تنظیم پراکسی pip / npm / git با یه دستور
- تشخیص خودکار سیستم‌عامل و معماری (Termux arm64، لینوکس، مک، ویندوز)
- سازگار با صفحه‌ی باریک گوشی
- **داشبورد وب** که خودکار بالا میاد: مدیریت ساب‌ها، دیدن کانفیگ‌ها با پینگ، حجم مصرفی نشست، وصل/قطع و تغییر سرور، افزودن ساب یا کانفیگ جدید

## نصب

**Termux**
```bash
pkg install python git
git clone https://github.com/rv9cy/tvpn.git
cd tvpn
python tvpn.py
```

**لینوکس / مک**
```bash
git clone https://github.com/rv9cy/tvpn.git
cd tvpn
python3 tvpn.py
```

**ویندوز (PowerShell)**
```powershell
git clone https://github.com/rv9cy/tvpn.git
cd tvpn
python tvpn.py
```

**نصب به‌صورت دستور `tvpn`**
```bash
pip install git+https://github.com/rv9cy/tvpn.git
tvpn
```

> اگه دانلود از GitHub برات بسته‌ست، فایل zip نسخه‌ی Xray رو دستی بگیر و باینری `xray` رو تو پوشه‌ی `~/.tvpn/bin/` بذار، یا متغیر `XRAY_MIRROR` رو روی یه میرور ست کن.

## نحوه‌ی استفاده

```bash
tvpn add https://example.com/sub/yourtoken   # افزودن ساب‌لینک (یا لینک vless:// vmess:// trojan:// ss://)
tvpn                                         # منوی تعاملی
tvpn up                                      # انتخاب کشور و اتصال
tvpn up germany                              # اتصال مستقیم به یه کشور
tvpn up auto                                 # کمترین تأخیر بین همه

eval "$(tvpn env)"                           # رد کردن همین شل از تونل (لینوکس/Termux/مک)
tvpn run pip install requests                # فقط همین دستور از تونل
tvpn tools on                                # تنظیم پراکسی pip / npm / git
tvpn check github.com                        # تست سایت: مستقیم در برابر تونل
tvpn down                                    # قطع اتصال
```

| دستور | توضیح |
|---|---|
| `tvpn` | منوی تعاملی |
| `tvpn up [country\|auto]` | اتصال |
| `tvpn down` | قطع اتصال |
| `tvpn status` | وضعیت اتصال |
| `tvpn add <link>` | افزودن ساب‌لینک یا لینک کانفیگ |
| `tvpn update` | به‌روزرسانی ساب‌لینک‌های ذخیره‌شده |
| `tvpn list` | لیست کانفیگ‌ها |
| `tvpn test` | تأخیر هر کشور |
| `tvpn env` | چاپ متغیرهای محیطی پراکسی |
| `tvpn run <cmd>` | اجرای یه دستور از تونل |
| `tvpn check <site>` | مقایسه‌ی دسترسی مستقیم و تونل |
| `tvpn tools on\|off` | تنظیم یا حذف پراکسی pip / npm / git |

کشور از روی اسم کانفیگ تشخیص داده می‌شه (ایموجی پرچم یا اسم کشور، مثلاً `🇩🇪 Germany-1`).

## داشبورد وب

هر بار `tvpn` رو اجرا کنی، یه داشبورد محلی تو پس‌زمینه بالا میاد و لینکش تو پنل STATUS نشون داده می‌شه:

```
│ Web UI   http://127.0.0.1:8787/?t=57c55298c8f0
```

لینک رو تو مرورگر باز کن (تو Termux، هر مرورگر همون گوشی). از اونجا می‌تونی وصل و قطع کنی، سرور عوض کنی، پینگ همه‌ی سرورها رو بگیری، ساب‌ها رو آپدیت یا حذف کنی و ساب یا کانفیگ جدید اضافه کنی.

- فقط محلیه: روی `127.0.0.1` گوش می‌ده و توکن تصادفی داخل لینک لازمه.
- `tvpn web` لینک رو چاپ می‌کنه و `tvpn web stop` متوقفش می‌کنه. پورت با `TVPN_WEB_PORT` عوض می‌شه.
- داشبورد به پوشه‌ی `web/` نیاز داره، پس پروژه رو از ریپوی کلون‌شده اجرا کن.

## چطور کار می‌کنه؟

```
دستور تو ──► 127.0.0.1:10808 (SOCKS5) / :10809 (HTTP)
                    │
              Xray-core (فضای کاربر)
                    │
            سرور ریموت تو ──► اینترنت
```

TVPN یه مدیر کلاینته: Xray رو با کانفیگ ساخته‌شده اجرا می‌کنه و یه پراکسی محلی بالا میاره. داده‌ها تو `~/.tvpn` ذخیره می‌شن.

## نکات مهم

- **TVPN سرور نمی‌ده.** باید کانفیگ یا ساب‌لینک خودت رو داشته باشی.
- فقط ابزارهایی که متغیرهای پراکسی رو می‌شناسن (یا با `tvpn tools` تنظیم شدن) از تونل رد می‌شن. کل ترافیک سیستم گرفته نمی‌شه.
- رعایت قوانین کشورت و شرایط سرویس‌دهنده‌ی سرور با خودته.
